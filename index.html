UI Builder Guide

Click a component on the left to add it to your UI. Click an element inside the preview to select it.

Use the Properties panel to change its text, colors, size, spacing, radius and typography.

Use Undo and Redo to move through your changes.

Select Mobile, Tablet, Laptop or Desktop to test your interface at different viewport sizes.

Export Code generates a standalone HTML file containing your current UI.
